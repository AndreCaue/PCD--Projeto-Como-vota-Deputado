
    **Component layout:**
    Outer container: `mb-6` (to maintain spacing from the section above/below).

    **Toggle header** (clickable button, not a Link):
    - Renders as a `div` with `flex items-center justify-between p-4 bg-gray-900 border border-gray-800 rounded-2xl cursor-pointer hover:border-gray-600 transition-all`
    - Left side:
      - Heading: `<h2 className="text-lg font-bold flex items-center gap-2"><Building2 className="w-5 h-5" /> Relações QSA</h2>` (Building2 from lucide-react)
    - Right side:
      - Chevron icon (ChevronDown when collapsed, ChevronUp when expanded) in gray-500
    - On click: toggle local `useState<boolean>` for expanded state

    **Collapsed state** (default):
    Just the toggle header row — no body content visible.

    **Expanded state** — lazy-loaded:
    - Local state: `relacoes: RelacaoDetalhada[] | null`, `loading: boolean`, `error: string | null`
    - On first expand: call `qsaService.relacoes(deputadoId)`
    - On subsequent expand/collapse: toggle display without re-fetching (cache the data in state)

    - **Loading state**: Show 3 `<Skeleton>` rows with `h-16 rounded-xl mb-2` spacing.
    - **Error state**: Show inline error message "Erro ao carregar relações" in text-sm text-red-400 with a retry button "Tentar novamente" (text-xs text-brasil-amarelo hover:underline cursor-pointer) that re-triggers the fetch.
    - **Empty state**: Show centered "Nenhuma relação encontrada" (text-sm text-gray-500 py-8) matching QsaEmptyState nodata variant style.

    - **Data loaded**: Render relationship items in a list below the header:
      - Container: `bg-gray-900 border border-gray-800 border-t-0 rounded-b-2xl p-4`
      - Each item: diverging from the full card style — more compact since this is inline on a profile page
      - Each relationship row: `flex flex-col gap-2 py-3 border-b border-gray-800 last:border-b-0`
      - Row content:
        - First line: Company name (`razao_social`, text-sm font-medium text-gray-100)
        - Second line: CNPJ formatted `XX.XXX.XXX/XXXX-XX` (text-xs font-mono text-gray-400)
        - Third line: `{capital_social ? "R$ " + capital_social.toLocaleString('pt-BR', { minimumFractionDigits: 2 }) : ""}` (text-xs font-semibold font-mono)
        - Fourth line (badge row): `flex flex-wrap gap-2 mt-1` with all 4 badges: `ConflictBadge` (hasConflict=conflito_interesse, score=score_conflito), `MatchTypeBadge` (relationshipType=relationship_type), `ExposureIndicator` (altaExposicao=alta_exposicao, capitalSocial=empresa.capital_social), `SpouseDisclosure` (viaConjuge=via_conjuge)

    **Animation**: Use framer-motion `AnimatePresence` with `motion.div` for the expanded body (height transition: `initial={{ height: 0, opacity: 0 }} animate={{ height: "auto", opacity: 1 }} exit={{ height: 0, opacity: 0 }}`).
