**Block A: Add helper method `_get_alta_threshold()` to RelacaoService:**

After `__init__`, add a new method:
```python
def _get_alta_threshold(self) -> float:
    from ..models.config import Config
    config = self.db.query(Config).filter(
        Config.key == "alta_exposicao_threshold").first()
    return float(config.value) if config else 1000000.0
```
This reads the threshold from the Config table, falling back to default 1,000,000 if no config row exists.

**Block B: Extend `gerar_relacoes_deputado()` to compute flags:**

Inside `gerar_relacoes_deputado`, before the delete+re-insert block (before line 66):
