Add a new endpoint to `deputados.py` — `GET /empresas` on the existing `router`:

Add after the existing route definitions (after `get_estatisticas_deputado` at line 140 or before). Follow the `list_deputados` pagination pattern exactly.

```python
@router.get("/empresas")
def list_deputados_empresas(
    partido: str = None,
    estado: str = None,
    tem_conflito: bool = None,
    alta_exposicao: bool = None,
    page: int = Query(1, ge=1, le=200),
    limit: int = Query(50, ge=1, le=200),
    db: Session = Depends(get_db)
):
    from sqlalchemy import func, Integer, case

    query = (
        db.query(
            Deputado.id,
            Deputado.nome,
            Partido.sigla.label("partido"),
            Deputado.estado,
            func.count(Relacao.cnpj).label("total_empresas"),
        )
        .outerjoin(Relacao, Deputado.id == Relacao.deputado_id)
        .outerjoin(Partido, Deputado.partido_id == Partido.id)
    )

    if partido:
        query = query.filter(Partido.sigla == partido.upper())
    if estado:
        query = query.filter(Deputado.estado == estado.upper())
    if tem_conflito is not None:
        # tem_conflito = has any relationship (total_empresas > 0)
        if tem_conflito:
            query = query.filter(Relacao.cnpj.isnot(None))
        else:
            query = query.having(func.count(Relacao.cnpj) == 0)

    query = query.group_by(Deputado.id).order_by(func.count(Relacao.cnpj).desc())

    total = db.query(func.count()).from_select(query.subquery()).scalar()
    rows = query.offset((page - 1) * limit).limit(limit).all()

    # Inline freshness from qsa_metadata
    from ..models.qsa_metadata import QsaMetadata
    from datetime import datetime
    meta = db.query(QsaMetadata).order_by(
        QsaMetadata.last_import_at.desc()).first()
    freshness = {}
    if meta:
        days_stale = (datetime.utcnow() - meta.last_import_at).days
        freshness = {
            "qsa_data_disponivel": True,
            "ultima_atualizacao_qsa": meta.last_import_at.isoformat(),
            "dias_desde_atualizacao": days_stale,
            "dados_antigos": days_stale > 45,
        }
    else:
        freshness = {"qsa_data_disponivel": False}

    return {
        "data": [
            {
                "id": r.id,
                "nome": r.nome,
                "partido": r.partido,
                "estado": r.estado,
                "total_empresas": r.total_empresas,
            }
            for r in rows
        ],
        "meta": {
            "total": total,
            "page": page,
            "limit": limit,
            "totalPages": (total + limit - 1) // limit if total > 0 else 0,
        },
        "freshness": freshness,
    }
```

**Important implementation notes:**
- Use `Query(ge=1, le=200)` on both `page` and `limit` per ASVS L1 input validation (security requirement).
- The `tem_conflito` filter: when `tem_conflito=True`, filter to rows where Relacao.cnpj IS NOT NULL (has at least one relationship). When `False`, use `HAVING COUNT(cnpj) = 0`.
- If `tem_conflito=True` filter and `alta_exposicao` is also provided, they should compound as AND filters.
- For `alta_exposicao` filter: need to add a join condition on Relacao. Use `query.filter(Relacao.alta_exposicao == alta_exposicao)` — this naturally applies to the outerjoin's ON clause.

Add import for `Relacao` and `Partido` if not already imported. The current `deputados.py` imports `Partido` already (line 5). Add `Relacao` import:
```python

```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Denial of Service | `GET /deputados/empresas` page/limit | mitigate | `Query(ge=1, le=200)` on both `page` and `limit` per ASVS V5 input validation. Limits maximum query window to 200×200=40,000 rows. |
| T-02-10 | Tampering | SQL injection via filter params (partido, estado) | mitigate | All filters use SQLAlchemy ORM parameterized queries (`Partido.sigla == partido.upper()`). No raw SQL concatenation. |
| T-02-11 | Tampering | `tem_conflito` and `alta_exposicao` bool filters | mitigate | Boolean type coercion via FastAPI `bool = None` — FastAPI validates `true`/`false` strings. Invalid values return 422. |
| T-02-12 | Information Disclosure | Deputy data exposure | accept | All data is public (deputados are public officials). No PII beyond what's already in the public domain. |
| T-02-SC | Tampering | package installs | mitigate | No new packages in this plan. All dependencies existing. |
